Programming Language PG0.5
Library Reference (Windows version)
--
# Introduction
PG0 is a programming language designed for learning programming.
PG0.5 extends the PG0 programming language.

The Windows version of PG0 provides the same libraries as the web version (pg0.jp) as DLLs.
Code written for the web version runs as is.
* Screen API (screen.pg0)
* Mathematical API (math.pg0)
* String API (string.pg0)
* Input/Output API (io.pg0)
* Network API (net.pg0)

# Files
The libraries are placed in the lib folder in the same directory as pg0.exe (pg0cmd.exe).
	pg0.exe
	pg0cmd.exe
	lib\screen.pg0     Screen API (script that loads pg0_screen.dll)
	lib\pg0_screen.dll
	lib\math.pg0       Mathematical API
	lib\pg0_math.dll
	lib\string.pg0     String API
	lib\pg0_string.dll
	lib\io.pg0         Input/Output API
	lib\pg0_io.dll
	lib\net.pg0        Network API
	lib\pg0_net.dll
Building the solution (PG0.sln) places them in the lib folder of the output directory.
The source code is in the pg0lib folder. Sample scripts are in pg0lib\samples.
(When installed with the installer, the sample scripts are in the sample\lib folder of the installation folder.)

# Import
The libraries can be used with the same import statements as the web version.
	#import("lib/screen.pg0")
	#import("lib/math.pg0")
	#import("lib/string.pg0")
	#import("lib/io.pg0")
	#import("lib/net.pg0")
#import searches in the following order.
	1) Relative path from the directory of the script file
	2) Relative path from the current directory
	3) Relative path from the directory of pg0.exe
	4) Load as a library (DLL)
	   Libraries are searched in the directory of the importing script, the current directory,
	   and the directory of pg0.exe, in that order.
Both "/" and "\" can be used as path separators.
If the extension is .dll, the file is loaded as a library without searching for a script.

# Differences from the web version
* The screen is displayed in a separate window.
	The screen window has the following buttons at the top right.
		Sound         Turns sound on/off (the setting is saved)
		Full screen   Switches to full screen. In full screen, a "restore" button is shown in the same place
	The F11 key also toggles full screen. The F11 key cannot be read with inKey().
	Closing the window stops the running script.
	The screen is displayed with Direct2D (GPU). If Direct2D is not available, GDI is used.
	Setting the environment variable PG0_SCREEN_GDI (to any value) forces display with GDI.
	Scaling and rotation in drawImage() are processed with multiple threads (default: number of CPUs - 1, up to 7).
	The number of threads can be changed with the environment variable PG0_SCREEN_THREADS (0 for a single thread, up to 15).
	Drawing functions and window repainting run in separate threads,
	and the window is repainted up to about 200 times per second.
	The window position and size, the full screen state, and sound on/off are
	saved in %LOCALAPPDATA%\pg0\pg0_screen.ini and restored the next time.
* Values of saveValue() are saved in %LOCALAPPDATA%\pg0\values.
	The values are stored separately for each script file name.
	Scripts with the same file name share the storage area even if they are in different folders.
	Scripts that have not been saved to a file share a common storage area.
* When running with pg0cmd.exe, pressing the close button of the screen window terminates pg0cmd.exe.
* The Network API (net.pg0) works when pg0.exe runs a program stored online
	(opened with "Browse online..." or saved with "Save to online...").
	It connects to the server of the settings (pg0.jp) with the cid of that program,
	so people who have the same program open in the web version can join the same room.
	A program built from a program stored online works as well (see "Building a program").
	A program opened from a file and pg0cmd.exe have no cid: netJoin() returns 0 there.

# Running from the command line (pg0cmd.exe)
Runs a script from the command line.
	pg0cmd [-psxvcj] [--option...] [file.pg0] [arg1 [arg2...]]
		-p	PG0 mode (no PG0.5 extensions)
		-s	Strict variable declaration
		-x	Hex result
		-v, --version	Version
		-c, --check	Syntax check only (the script is not run)
		-j, --json	Output the result as JSON (UTF-8)
		--utf8	UTF-8 input and output (the default is the code page of Windows)
		--timeout=ms	Time limit (milliseconds)
		--max-steps=n	Limit of executed steps
		--input=file	File read line by line by input() (UTF-8)
		--headless	No window and no sound for the screen
		--screenshot=file	Save the screen as PNG at the end
		--screen-input=file	File of key and touch operations for the screen
		file.pg0	When omitted, lines are read from the standard input and executed
		arg1	Arguments passed to the script (argv, argc)
Single letter options can be combined as in "-psx" ("/psx" is also accepted).
The exit code is 0 for a normal end, 1 for an error (syntax error, runtime error, wrong file or option),
and 2 when the script was stopped by the time or step limit.
print() of an array outputs it in the same format as pg0.exe.
input() reads a line from the file of --input, the redirected standard input, or the console.
At the end of the file or the redirected input it returns the integer 0, as the web version does.

* JSON output (-j)
	The result is output as one line of JSON, in the same format as the result of the AI agent API of the web version.
		status           "ok", "error", "timeout" or "step_limit" (stopped by a limit)
		mode             The mode the script ran in ("PG0.5" or "PG0")
		output           Output of print() (output_truncated is true past 1,000,000 characters)
		error_output     Output of error() and the error messages
		result           Value of exit (result_type is "integer", "float", "string" or "array")
		error            {"message", "line", "phase"}  phase is "parse" or "runtime"
		variables        Global variables at the end, the stop or the error (names and keys in lower case)
		screen           {"width", "height", "screenshots": [saved PNG files]} when the screen is used
		stats            {"steps", "elapsed_ms", "input_lines_used"}
	With -c, {"ok", "mode", "error"} is output.
	With --timeout, a script that does not stop within 3 seconds after the limit (a loop in an
	imported script, or waiting for input) is terminated. In that case variables is null.

* Checking the screen (--headless, --screenshot, --screen-input)
	With --headless the screen is drawn without showing a window.
	(Running with the environment variable PG0_SCREEN_HEADLESS set does the same)
	--screenshot saves the screen at the end (or at the stop by a limit) as a PNG file.
	The file of --screen-input has one operation per line. The operations are performed in order,
	starting when startScreen() is called. The coordinates are those of startScreen().
		wait ms                  Wait
		key name [ms]            Press and release a key (100 ms by default); the space key is Space
		keydown name             Hold a key down
		keyup name               Release a key
		tap x y                  Touch (click)
		press x y ms             Keep touching for the time
		drag x1 y1 x2 y2 [ms]    Drag (300 ms by default)
		move x y                 Move the position without touching
		screen file.png          Save the screen at that moment as PNG
	Lines beginning with "#" or "//" are comments.
		e.g. pg0cmd -j --headless --timeout=3000 --screenshot=end.png --screen-input=ops.txt game.pg0

# Working with AI agents
AI agents such as Claude Code can write PG0 / PG0.5 scripts.
* AGENTS.md
	AGENTS.md in the same directory as pg0.exe is the guide for AI agents (in Japanese).
	It describes the essentials of the language, common mistakes, and how to check and run scripts with pg0cmd.exe.
	Copy it into the folder of your scripts, then start the AI agent in that folder.
* Reloading changes
	When another program (such as an AI agent) changes the file opened in pg0.exe,
	pg0.exe reloads it automatically and shows the first changed line.
	If there are unsaved changes, it asks whether to reload.
	While a script is running, the file is reloaded after the script ends.
	"Show external changes..." in the File menu shows the changes from the text that was
	opened (or saved), in the same view as the revision history.

# Building a program (pg0gen.exe)
A script can be turned into a stand-alone program (.exe).
	pg0gen [/pswc] file.pg0 [out.exe]
		p	PG0 mode (no PG0.5 extensions)
		s	Strict variable declaration
		w	Window application
		c	Console application
		out.exe	Default: an .exe with the same name next to the script
In pg0.exe, "Create EXE file..." in the File menu builds a program from the script being edited
(choose the output file; pg0gen.exe is run and its output is shown in the console pane).
pg0gen.exe parses the script and embeds the parse tree (the internal form used for execution)
into the resources of a template program. The program does not contain the source of the
script and does not parse the script when it runs.
	pg0app.exe	Template of a console application
	pg0appw.exe	Template of a window application (no console window)
The templates are placed in the same directory as pg0gen.exe.
Without /w or /c, the program is a window application when the screen library (lib/screen.pg0)
is used, and a console application otherwise.
The five libraries screen, math, string, io and net are built into the program, so the program
needs neither the lib folder nor the DLLs.
For a script that uses the Network API (net.pg0), a program built in pg0.exe from a program
stored online (opened with "Browse online..." or saved with "Save to online...") carries the cid
and the server of that program. Whoever runs it joins the same rooms as the people playing the same
program as a built program, in pg0.exe or in the web version. Otherwise netJoin() returns 0.
(On the command line, give the cid and the server in the environment variables PG0_CID and PG0_SERVER.)
Other libraries (DLLs loaded with #library) are loaded from the directory of the program
(or its lib folder); pg0gen.exe copies the required DLLs to the output directory.
Imported scripts (#import) are included in the program as well.
Command line arguments are available as argv and argc (as with pg0cmd.exe).
In a window application the output of print() is not shown
(when started from a command prompt, it is written to that command prompt).
input() returns an empty string, and error() and errors are shown in a message box.
The screen window closes when the script ends.

# Screen API (screen.pg0)
Can be used with the following import statement.
	#import("lib/screen.pg0")

startScreen(width, height, option)
	* Description
		Starts the screen.
		Displays a screen of the specified size in a separate window.
	* Parameters
		width - Screen width (number)
		height - Screen height (number)
		option - Specify options as an associative array.
					{"color": Hexadecimal color code (string), "fit": Flag whether to adapt to screen size(number)}
	* Return Value
		0

sleep(time)
	* Description
		Stops processing for a certain period of time.
	* Parameters
		time - Specify the stopping time in milliseconds as a numerical value.
	* Return Value
		0

time()
	* Description
		Gets the current time (UTC).
	* Parameters
		None
	* Return Value
		Returns the number of milliseconds that have passed since January 1, 1970 00:00:00.

timeString(time, format)
	* Description
		Format a time into a date/time string.
	* Parameters
		time - Number of milliseconds elapsed since January 1, 1970 00:00:00
		format - date and time format. If omitted, the string will be formatted according to the locale.
					YYYY - year
					MM or M - month
					DD or D - day
					hh or h - hour
					mm or m - minutes
					ss or s - seconds
	* Return Value
		date and time string

startOffscreen()
	* Description
		Start off-screen and draw the screen display off-screen.
	* Parameters
		None
	* Return Value
		0

endOffscreen()
	* Description
		Exit off-screen and draw the contents of the off-screen to the screen.
	* Parameters
		None
	* Return Value
		0

startMask(option)
	* Description
		Start mask drawing mode.
		While in mask drawing mode, only the areas you draw on will remain visible; everything else will be transparent.
	* Parameters
		option - Specify options as an associative array.
					{"destination": Mask destination (string)}
					If you specify "out", the drawn area will become transparent.
	* Return Value
		0

endMask()
	* Description
		Exit mask drawing mode.
	* Parameters
		None
	* Return Value
		0

clearRect(x, y, width, height)
	* Description
		Makes the area transparent.
	* Parameters
		x - upper left horizontal coordinate (number)
		y - vertical coordinate of top left (number)
		width - width (number)
		height - height (number)
	* Return Value
		0

drawLine(x1, y1, x2, y2, option)
	* Description
		Draw a line.
	* Parameters
		x1 - starting horizontal coordinate (number)
		y1 - starting vertical coordinate (number)
		x2 - horizontal coordinate of end (number)
		y2 - vertical coordinate of end (number)
		option - Specify options as an associative array.
					{"width": line width (number), "color": hexadecimal color code (string)}
	* Return Value
		0

drawRect(x, y, width, height, option)
	* Description
		Draw a rectangle.
	* Parameters
		x - upper left horizontal coordinate (number)
		y - vertical coordinate of top left (number)
		width - width (number)
		height - height (number)
		option - Specify options as an associative array.
					{"width": line width (number), "color": hexadecimal color code (string), "fill": fill (number)}
					Setting the fill to 1 will fill the rectangle with the specified color.
	* Return Value
		0

drawCircle(x, y, radiusX, option)
	* Description
		Draw a circle.
	* Parameters
		x - horizontal coordinate of the center of the circle (number)
		y - vertical coordinate of the center of the circle (number)
		radiusX - horizontal radius (number)
		option - Specify options as an associative array.
					{"width": line width (number), "color": hexadecimal color code (string), "fill": fill (number), "radius_y": vertical radius (number), "rotation": tilt of the circle (radians), "start": angle clockwise from the X-axis where the circle starts (radians), "end": angle clockwise from the X-axis where the circle ends (radians), "close": connect both ends of the arc (number)}
					Setting fill to 1 will fill the circle with the specified color.
					When radius_y is omitted, the radius is the same as radiusX.
					Setting close to 1 connects both ends of the arc with a straight line.
	* Return Value
		0

drawPolyline(coordinates, option)
	* Description
		Draw a series of straight lines connected by several coordinates.
	* Parameters
		coordinates - Array of coordinates
						Ex) drawPolyline({{100, 100}, {200, 100}, {150, 50}}, {"close": 1}) // Triangle
		option - Specify options as an associative array.
					{"width": line width (number), "color": hexadecimal color code (string), "fill": fill (number), "close": connect the last line with the first line (number)}
	* Return Value
		0

drawFill(x, y, color)
	* Description
		Fills the specified coordinates with the specified color.
		Traces adjacent pixels and fills them with specified color.
	* Parameters
		x - horizontal coordinate (number) to start filling
		y - vertical coordinate to start filling (number)
		color - hexadecimal color code (string)
	* Return Value
		0

drawScroll(x, y)
	* Description
		Scroll the screen.
		Areas that extend beyond the screen will be displayed on the opposite side.
	* Parameters
		x - horizontal scroll amount (number)
		y - vertical scroll amount (number)
	* Return Value
		0

createImage(x, y, width, height, option)
	* Description
		Creates an image of the specified area.
		The returned Image ID can be drawn with drawImage().
	* Parameters
		x - upper left horizontal coordinate (number)
		y - vertical coordinate of top left (number)
		width - width (number)
		height - height (number)
		option - Specify options as an associative array.
					{"id": Image ID (number)}
					If an id is specified, it replaces the existing image.
	* Return Value
		Image ID

drawImage(id, x, y, option)
	* Description
		Draws an image of the specified Image ID.
	* Parameters
		id - Image ID
		x - upper left horizontal coordinate (number)
		y - vertical coordinate of top left (number)
		option - Specify options as an associative array.
					{"width": width (number), "height": height (number), "angle": drawing angle (radians), "alpha": transparency (number)}
					When only one of width and height is specified, the other is the size of the original image.
					alpha is specified between 0.0 and 1.0.
	* Return Value
		0

drawText(text, x, y, option)
	* Description
		Draw text.
	* Parameters
		text - the text to draw (string)
		x - starting horizontal coordinate (number)
		y - starting vertical coordinate (number)
		option - Specify options as an associative array.
					{"width": line width (number), "color": hexadecimal color code (string), "fill": fill (number), "fontstyle": font style (string), "fontsize": font size (number), "fontface": font (string)}
					The default for fill is 1, and if you specify 0, hollow characters will be drawn.
					Specify the font style as normal, bold, italic, or oblique.
	* Return Value
		0

measureText(text, option)
	* Description
		Gets the text drawing size.
	* Parameters
		text - text (string)
		option - Specify options as an associative array.
					{"fontstyle": font style (string), "fontsize": font size (number), "fontface": font (string)}
					Specify the font style as normal, bold, italic, or oblique.
	* Return Value
		drawing size
		{"width": width, "height": height}

rgbToPoint(x, y)
	* Description
		Gets the color at the specified coordinates.
	* Parameters
		x - horizontal coordinate (number)
		y - vertical coordinate (number)
	* Return Value
		RGB array
		{"r": numbers up to 255 to indicate red, "g": numbers up to 255 to indicate green, "b": numbers up to 255 to indicate blue}

rgbToHex(rgb)
	* Description
		Converts an RGB array to hexadecimal color code.
	* Parameters
		rgb - RGB array
				{"r": numbers up to 255 to indicate red, "g": numbers up to 255 to indicate green, "b": numbers up to 255 to indicate blue}
				The keys are case-insensitive.
	* Return Value
		Hexadecimal color code (string)

hexToRgb(hex)
	* Description
		Converts a hexadecimal color code to an RGB array.
	* Parameters
		hex - Hexadecimal color code (string)
	* Return Value
		RGB array
		{"r": numbers up to 255 to indicate red, "g": numbers up to 255 to indicate green, "b": numbers up to 255 to indicate blue}

inTouch()
	* Description
		Returns the touch (mouse) position.
	* Parameters
		None
	* Return Value
		touch state
		{"x": horizontal coordinate, "y": vertical coordinate, "touch": touch state, "button": button, "pos": {{horizontal coordinate, vertical coordinate}, ...}}
		If the touch status is 0, it is not currently touched and will be the last touched coordinate.
		For button, 0 is left click, 1 is middle (wheel) click, and 2 is right click.
		pos contains multi-touch coordinates.

inKey(key)
	* Description
		Returns keyboard input.
	* Parameters
		key - Specifies the key string to check if pressed.
				If specified as an array, check that all key strings in the array are pressed.
				The key string will be equivalent to JavaScript's KeyboardEvent.key.
	* Return Value
		If no argument is specified, an array of pressed key strings is returned.
		If the argument is specified as a string, it returns 1 if the key is pressed and 0 if not.
		If the argument is specified as an array, it returns 1 if all keys are pressed and 0 if any keys are not pressed.

playSound(note, start, end, volume = 1)
	* Description
		Plays the specified frequency for the specified time.
	* Parameters
		note - frequency (number)
				If a string is specified, it will be converted to the corresponding frequency. If you put a number after it, it will be converted to an octave.
				'C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'
				When the octave is omitted it is 4. Flats (b) are not supported.
					Ex) playSound("C4", 0, 500)
		start - milliseconds until the sound starts (number)
		end - length of the sound from start in milliseconds (number)
		volume - volume, default is 1 (number)
	* Return Value
		0

playMusic(notes, option)
	* Description
		Play multiple frequencies in sequence.
	* Parameters
		notes - Array of notes
				{note, length, volume}
				If a string is specified, it will be converted to the corresponding frequency. If you put a number after it, it will be converted to an octave.
				'C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'
				When the octave is omitted it is 4. Flats (b) are not supported.
					Ex) playMusic({{"C4", 500}, {"D4", 500}, {"E4", 500}})
				volume is optional.

				The following keys and values in the array have a special meaning.
				start: start position, if several sounds are played at the same time, set the start position to 0 and another sound.
					Ex) playMusic({{"C4", 800}, {"start": 0}, {"E4", 800}, {"start": 0}, {"G4", 800}})
				volume: Volumes after this.
		option - Specify options as an associative array.
					{"repeat": repetition flag(number)}
	* Return Value
		0

bgm(notes, option)
	* Description
		Plays background music.
		Stops the background music that is playing, if any, then plays notes repeatedly.
		Sound effects started with playSound() or playMusic() keep playing.
		Without notes, stops the background music.
			Ex) bgm({{"C4", 500}, {"E4", 500}, {"G4", 500}})
			Ex) bgm() // stop the background music
	* Parameters
		notes - Array of notes in the same format as playMusic(), optional
		option - Specify options in an associative array.
					{"repeat": repeat flag (number)}
					Default is 1 (repeat). 0 plays the notes once.
	* Return Value
		0

stopSound()
	* Description
		Stop any sound that is playing.
		Background music started with bgm() is stopped as well.
	* Parameters
		None
	* Return Value
		0

# Mathematical API (math.pg0)
Can be used with the following import statement.
	#import("lib/math.pg0")

abs(num)
	* Description
		Returns the absolute value.
	* Parameters
		num - number
	* Return Value
		Absolute value

atan(num)
	* Description
		Returns the arctangent in radians.
	* Parameters
		num - number
	* Return Value
		arctangent of argument

atan2(y, x)
	* Description
		Returns the angle from the origin to the point (x, y) in radians.
		The angle is measured from the positive x axis and lies between -π and π.
			Ex) atan2(1, 1) // 0.785... (45 degrees)
	* Parameters
		y - Vertical value
		x - Horizontal value
	* Return Value
		Angle in radians

cos(num)
	* Description
		Returns the cosine.
	* Parameters
		num - number
	* Return Value
		cosine of argument

exp(num)
	* Description
		Returns e (the base of the natural logarithm) raised to the power of num.
	* Parameters
		num - number
	* Return Value
		e raised to the power of num

log(num)
	* Description
		Returns the natural logarithm.
	* Parameters
		num - number
	* Return Value
		natural logarithm

random(seed)
	* Description
		Returns a random number.
		When seed is given, switches to a reproducible sequence that starts from that seed and returns its first value.
		Following random() calls continue the same sequence.
		Without a seed ever given, a different random number is returned each time.
	* Parameters
		seed - Seed of the sequence (number or string), optional
	* Return Value
		Random number greater than or equal to 0 and less than 1

sign(num)
	* Description
		Returns a flag indicating whether the sign of a number is positive or negative.
	* Parameters
		num - number
	* Return Value
		1 - positive
		-1 - negative
		0 - zero

sin(num)
	* Description
		Returns the sine.
	* Parameters
		num - number
	* Return Value
		sine of argument

sqrt(num)
	* Description
		Returns the square root.
	* Parameters
		num - number
	* Return Value
		square root

tan(num)
	* Description
		Returns the tangent.
	* Parameters
		num - number
	* Return Value
		tangent of argument

pow(base, exponent)
	* Description
		Returns the base raised to the power of the exponent.
	* Parameters
		base - Base
		exponent - Exponent
	* Return Value
		The base raised to the power of the exponent

max(a, b, ...)
	* Description
		Returns the largest of the arguments.
		When an array is given, its elements are compared.
			Ex) max(1, 5, 3) // 5
			Ex) max({4, 2, 9}) // 9
	* Parameters
		a, b, ... - Numbers or arrays of numbers
	* Return Value
		Largest value

min(a, b, ...)
	* Description
		Returns the smallest of the arguments.
		When an array is given, its elements are compared.
	* Parameters
		a, b, ... - Numbers or arrays of numbers
	* Return Value
		Smallest value

floor(num)
	* Description
		Returns the largest integer less than or equal to the number (rounds down).
			Ex) floor(2.7) // 2
			Ex) floor(-2.7) // -3
	* Parameters
		num - Number
	* Return Value
		Integer

ceil(num)
	* Description
		Returns the smallest integer greater than or equal to the number (rounds up).
			Ex) ceil(2.1) // 3
			Ex) ceil(-2.1) // -2
	* Parameters
		num - Number
	* Return Value
		Integer

round(num)
	* Description
		Returns the number rounded to the nearest integer.
			Ex) round(2.5) // 3
			Ex) round(-2.5) // -2
	* Parameters
		num - Number
	* Return Value
		Integer

hypot(x, y)
	* Description
		Returns the length of the hypotenuse (square root of x*x + y*y).
			Ex) hypot(3, 4) // 5
	* Parameters
		x - Number
		y - Number
	* Return Value
		Length of the hypotenuse

# String API (string.pg0)
Can be used with the following import statement.
	#import("lib/string.pg0")

trim(str)
	* Description
		Trims the front and back of a string.

# Network API (net.pg0)
Can be used with the following import statement.
	#import("lib/net.pg0")

People who have the same program open (the same program saved online, with the same cid) can send values to each other.
Use it for games played online against each other.
* It works only in a program saved online (saving gives the program a cid).
	In pg0.exe it works for a program opened with "Browse online..." or saved with "Save to online...",
	and in a program built from it.
* Only copies of the program with the same cid are connected; never other programs.
	People who have the same program open in the web version can join the same room.
* The server stores nothing: a value sent only reaches the other people in the room.
* When the program ends (including the stop button), it leaves the room.
* The size and number of values sent are limited (by default up to 16 KB each and 60 a second).
	What goes over is not sent, and a notice is shown in the console pane.
Example: two people send each other a position
	#import("lib/net.pg0")
	#import("lib/io.pg0")
	me = netJoin()
	if (me == 0) {
		println("Could not connect")
		exit
	}
	while (netCount() < 2) {
		wait(100)
	}
	x = 100 * me
	netSend({"x": x})
	while (netAvailable() == 0) {
		wait(100)
	}
	m = netReceive()
	println("x of player " + m["from"] + " is " + m["data"]["x"])

netJoin(room, players)
	* Description
		Enters a room, and waits until it is in the room or has failed (10 seconds at most).
		It is connected with the people of the same cid in the room of the same name.
		Without a room name (or with ""), it enters a room that is not full yet by itself.
		Once such an automatic room has been full, nobody else enters it.
		With a room name agreed beforehand, friends can enter the same room.
		A full room, or a room closed with netClose(), cannot be entered.
		When it is already in a room, it leaves that room first.
	* Parameters
		room - Room name (optional, up to 32 characters)
		players - Number of players of the room (2 when omitted, 2 to 8). The value of the person who made the room is used.
	* Return Value
		Your player number (1, 2, ...), or 0 when it could not enter.
		Numbers are given in the order of entering: the smallest number that is free.
		When it could not enter, the reason is shown in the console pane.

netLeave()
	* Description
		Leaves the room.
	* Parameters
		None
	* Return Value
		0

netClose()
	* Description
		Closes the room: nobody else can enter it any more.
		Call it when the game starts, and nobody comes in part-way through.
		Free seats, and seats left later, are not offered again.
		Anybody in the room may call it, and it cannot be undone.
	* Parameters
		None
	* Return Value
		1 when the room was closed, 0 when not in a room.
	Example: a game for 2 to 4 people that player 1 starts once 2 or more have come
		me = netJoin("", 4)
		if (me == 1) {
			while (netCount() < 2) {
				wait(100)
			}
			netClose()
			netSend("start")
		}

netId()
	* Description
		Gets your player number.
	* Parameters
		None
	* Return Value
		Your player number. 0 when not in a room (also after the connection was lost).

netRoom()
	* Description
		Gets the name of the room. A room entered automatically has a name starting with "auto-".
	* Parameters
		None
	* Return Value
		The room name. "" when not in a room.

netCount()
	* Description
		Gets the number of people in the room, you included.
	* Parameters
		None
	* Return Value
		The number of people. 0 when not in a room (also after the connection was lost).

netPlayers()
	* Description
		Gets the player numbers of the people in the room.
	* Parameters
		None
	* Return Value
		Array of player numbers, smallest first. Example: {1, 2}

netSend(value, to)
	* Description
		Sends a value: a number, a string or an array. It does not come back to you.
	* Parameters
		value - The value to send
		to - Player number to send it to (everybody else in the room when omitted)
	* Return Value
		1 when it was sent, 0 when it could not be (for example when not in a room).

netAvailable()
	* Description
		Gets the number of values received and not taken with netReceive() yet.
	* Parameters
		None
	* Return Value
		The number of values (1000 at most; past that the oldest are dropped).

netReceive()
	* Description
		Takes the oldest received value.
	* Parameters
		None
	* Return Value
		Array {"from": player number of the sender, "data": the value sent}.
		0 when nothing has been received.

netLast(player)
	* Description
		Gets the last value received from the given player, whether or not it was taken with netReceive().
		In a game where everybody keeps sending their position, this alone tells what the others are doing.
	* Parameters
		player - Player number
	* Return Value
		The last value received. 0 when nothing has come from that player yet, or when they left the room.
