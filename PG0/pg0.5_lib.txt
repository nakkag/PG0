プログラミング言語 PG0.5
ライブラリ リファレンス (Windows版)
--
■はじめに
PG0はプログラミング学習を目的としたプログラミング言語です。
PG0.5はPG0を拡張したプログラミング言語です。

Windows版のPG0では、Web版(pg0.jp)と同じライブラリをDLLとして提供します。
Web版と同じコードをそのまま動かすことができます。
・画面描画API (screen.pg0)
・数値処理API (math.pg0)
・文字列API (string.pg0)
・入出力API (io.pg0)

■ファイル構成
ライブラリは pg0.exe (pg0cmd.exe) と同じディレクトリの lib フォルダに置きます。
	pg0.exe
	pg0cmd.exe
	lib\screen.pg0     画面描画API (pg0_screen.dll を読み込むスクリプト)
	lib\pg0_screen.dll
	lib\math.pg0       数値処理API
	lib\pg0_math.dll
	lib\string.pg0     文字列API
	lib\pg0_string.dll
	lib\io.pg0         入出力API
	lib\pg0_io.dll
ソリューション(PG0.sln)をビルドすると、出力ディレクトリの lib フォルダに配置されます。
ソースは pg0lib フォルダにあります。サンプルスクリプトは pg0lib\samples にあります。
(インストーラでインストールした場合、サンプルスクリプトはインストール先の sample\lib にあります)

■インポート
Web版と同じインポート文でライブラリを利用できます。
	#import("lib/screen.pg0")
	#import("lib/math.pg0")
	#import("lib/string.pg0")
	#import("lib/io.pg0")
#importの検索順序は以下の通りです。
	1) スクリプトファイルのディレクトリからの相対パス
	2) カレントディレクトリからの相対パス
	3) pg0.exe のディレクトリからの相対パス
	4) ライブラリ(DLL)として読み込み
	   ライブラリはインポートしたスクリプトのディレクトリ、カレントディレクトリ、
	   pg0.exe のディレクトリの順に検索します。
パスの区切りは「/」と「\」のどちらも使えます。
拡張子が .dll の場合はスクリプトの検索を行わずにライブラリとして読み込みます。

■Web版との違い
・スクリーンは別ウィンドウに表示されます。
	スクリーンウィンドウの右上には以下のボタンがあります。
		サウンド      サウンドのオン/オフ(設定は保存されます)
		全画面        全画面表示に切り替えます。全画面中は同じ位置に「元に戻す」ボタンが表示されます
	F11キーでも全画面表示を切り替えられます。F11キーは inKey() では取得できません。
	ウィンドウを閉じると実行中のスクリプトを停止します。
	画面の表示にはDirect2D(GPU)を使います。Direct2Dが使えない環境ではGDIで表示します。
	環境変数 PG0_SCREEN_GDI を設定すると(値は任意)GDIでの表示を強制できます。
	drawImage()の拡大縮小・回転は複数のスレッドで処理します(既定はCPU数-1で最大7)。
	環境変数 PG0_SCREEN_THREADS でスレッド数を変更できます(0で単一スレッド、最大15)。
	描画関数の呼び出しとウィンドウの再描画は別スレッドで行われ、
	再描画は最大で毎秒200回程度になります。
	ウィンドウの位置とサイズ、全画面状態、サウンドのオン/オフは
	%LOCALAPPDATA%\pg0\pg0_screen.ini に保存され、次回の実行時に復元されます。
・saveValue() の値は %LOCALAPPDATA%\pg0\values に保存されます。
	保存先はスクリプトのファイル名ごとに分かれます。
	フォルダが異なっても同じファイル名のスクリプトは同じ保存先になります。
	ファイルに保存していないスクリプトは共通の保存先になります。
・pg0cmd.exe で実行中にスクリーンの閉じるボタンを押すと pg0cmd.exe を終了します。

■実行ファイルの作成 (pg0gen.exe)
スクリプトを単体の実行ファイル(.exe)にすることができます。
	pg0gen [/pswc] file.pg0 [out.exe]
		p	PG0モード(PG0.5の拡張を使わない)
		s	変数宣言を強制
		w	ウィンドウアプリケーションにする
		c	コンソールアプリケーションにする
		out.exe	省略時はスクリプトと同じ場所に同じ名前の .exe を作成
pg0.exe では「ファイル」メニューの「EXEファイルを作成(E)...」で、編集中のスクリプトから
実行ファイルを作成できます(出力先を選択すると pg0gen.exe が実行され、結果は実行結果欄に表示されます)。
pg0gen.exe はスクリプトを解析し、解析木(実行用の内部形式)をテンプレートの
実行ファイルのリソースに埋め込みます。作成した実行ファイルにスクリプトの
ソースは含まれず、実行時にスクリプトの解析は行いません。
	pg0app.exe	コンソールアプリケーションのテンプレート
	pg0appw.exe	ウィンドウアプリケーションのテンプレート(コンソールを表示しない)
テンプレートは pg0gen.exe と同じディレクトリに置きます。
/w /c を指定しない場合、screen ライブラリ(lib/screen.pg0)を使っていれば
ウィンドウアプリケーション、使っていなければコンソールアプリケーションになります。
screen / math / string / io の4つのライブラリは実行ファイルに組み込まれるため、
作成した実行ファイルの実行に lib フォルダや DLL は必要ありません。
それ以外のライブラリ(#library で読み込む DLL)は実行ファイルと同じディレクトリ
(またはその lib フォルダ)から読み込みます。pg0gen.exe は必要な DLL を出力先にコピーします。
#import したスクリプトも実行ファイルに含まれます。
コマンドライン引数は argv, argc で参照できます(pg0cmd.exe と同じ)。
ウィンドウアプリケーションでは print() の出力は表示されません
(コマンドプロンプトから起動した場合はそのコマンドプロンプトに出力します)。
input() は空文字列を返し、error() やエラーはメッセージボックスで表示します。
スクリプトが終了するとスクリーンのウィンドウも閉じます。

■画面描画API (screen.pg0)

以下のインポート文により利用することができます。
#import("lib/screen.pg0")

startScreen(width, height, option)
	[説明]
		スクリーンを開始します。
		指定したサイズのスクリーンを別ウィンドウに表示します。
	[引数]
		width - 画面の幅(数値)
		height - 画面の高さ(数値)
		option - オプションを連想配列で指定します。
					{"color": 16進数のカラーコード(文字列), "fit": 画面サイズに合わせるかのフラグ(数値)}
	[戻り値]
		0

sleep(time)
	[説明]
		一定時間処理を停止します。
	[引数]
		time - 停止する時間をミリ秒を数値で指定します。
	[戻り値]
		0

time()
	[説明]
		現在時刻(UTC)を取得します。
	[引数]
		なし
	[戻り値]
		1970年1月1日 00:00:00からの経過ミリ秒を数値で返します。

timeString(time, format)
	[説明]
		時間を日時文字列にフォーマットします。
	[引数]
		time - 1970年1月1日 00:00:00からの経過ミリ秒を数値
		format - 日時フォーマット。省略時はロケールに従った文字列にフォーマットされます。
					YYYY - 年
					MM or M - 月
					DD or D - 日
					hh or h - 時
					mm or m - 分
					ss or s - 秒
	[戻り値]
		日時文字列

startOffscreen()
	[説明]
		オフスクリーンを開始して、画面表示をオフスクリーンに描画します。
	[引数]
		なし
	[戻り値]
		0

endOffscreen()
	[説明]
		オフスクリーンを終了して、オフスクリーンの内容を画面に描画します。
	[引数]
		なし
	[戻り値]
		0

startMask(option)
	[説明]
		マスク描画モードを開始します。
		マスク描画モード中は描画した領域のみが残り、それ以外の部分は透明になります。
	[引数]
		option - オプションを連想配列で指定します。
					{"destination": マスクの場所(文字列)}
					"out"を指定すると描画した領域が透明になります。
	[戻り値]
		0

endMask()
	[説明]
		マスク描画モードを終了します。
	[引数]
		なし
	[戻り値]
		0

clearRect(x, y, width, height)
	[説明]
		指定領域の描画を透明化します。
	[引数]
		x - 左上の水平座標(数値)
		y - 左上の垂直座標(数値)
		width - 幅(数値)
		height - 高さ(数値)
	[戻り値]
		0

drawLine(x1, y1, x2, y2, option)
	[説明]
		直線を描画します。
	[引数]
		x1 - 開始の水平座標(数値)
		y1 - 開始の垂直座標(数値)
		x2 - 終了の水平座標(数値)
		y2 - 終了の垂直座標(数値)
		option - オプションを連想配列で指定します。
					{"width": 線幅(数値), "color": 16進数のカラーコード(文字列)}
	[戻り値]
		0

drawRect(x, y, width, height, option)
	[説明]
		四角を描画します。
	[引数]
		x - 左上の水平座標(数値)
		y - 左上の垂直座標(数値)
		width - 幅(数値)
		height - 高さ(数値)
		option - オプションを連想配列で指定します。
					{"width": 線幅(数値), "color": 16進数のカラーコード(文字列), "fill": 塗りつぶし(数値)}
					塗りつぶしに1を設定すると指定された色で四角を塗りつぶします。
	[戻り値]
		0

drawCircle(x, y, radiusX, option)
	[説明]
		円を描画します。
	[引数]
		x - 円の中心の水平座標(数値)
		y - 円の中心の垂直座標(数値)
		radiusX - 水平方向の半径(数値)
		option - オプションを連想配列で指定します。
					{"width": 線幅(数値), "color": 16進数のカラーコード(文字列), "fill": 塗りつぶし(数値), "radius_y": 垂直方向の半径(数値), "rotation": 円の傾き(ラジアン), "start": 円が始まるX軸から時計回りの角度(ラジアン), "end": 円の終わるX軸から時計回りの角度(ラジアン), "close": 円弧の両端を繋ぐ(数値)}
					塗りつぶしに1を設定すると指定された色で円を塗りつぶします。
					radius_yを省略した場合はradiusXと同じ半径になります。
					closeに1を設定すると円弧の両端を直線で繋ぎます。
	[戻り値]
		0

drawPolyline(coordinates, option)
	[説明]
		いくつかの座標で繋がった一連の直線を描画します。
	[引数]
		coordinates - 座標の配列
						例) drawPolyline({{100, 100}, {200, 100}, {150, 50}}, {"close": 1}) // 三角形
		option - オプションを連想配列で指定します。
					{"width": 線幅(数値), "color": 16進数のカラーコード(文字列), "fill": 塗りつぶし(数値), "close": 1の場合は最後の線と最初の線を繋げる(数値)}
	[戻り値]
		0

drawFill(x, y, color)
	[説明]
		指定座標の色を指定の色で塗りつぶします。
		隣接するピクセルを辿って指定の色で塗りつぶします。
	[引数]
		x - 塗りつぶしを開始する水平座標(数値)
		y - 塗りつぶしを開始する垂直座標(数値)
		color - 16進数のカラーコード(文字列)
	[戻り値]
		0

drawScroll(x, y)
	[説明]
		画面をスクロールします。
		画面からはみ出た領域は逆側に表示されます。
	[引数]
		x - スクロールする水平の移動量(数値)
		y - スクロールする垂直の移動量(数値)
	[戻り値]
		0

createImage(x, y, width, height, option)
	[説明]
		指定領域の画像を作成します。
		戻り値を使ってdrawImage()で描画することができます。
	[引数]
		x - 左上の水平座標(数値)
		y - 左上の垂直座標(数値)
		width - 幅(数値)
		height - 高さ(数値)
		option - オプションを連想配列で指定します。
					{"id": 既存のイメージID(数値)}
					idを指定した場合は既存の画像を置き換えます。
	[戻り値]
		イメージID

drawImage(id, x, y, option)
	[説明]
		指定イメージIDの画像を描画します。
	[引数]
		id - イメージID
		x - 左上の水平座標(数値)
		y - 左上の垂直座標(数値)
		option - オプションを連想配列で指定します。
					{"width": 幅(数値), "height": 高さ(数値), "angle": 角度(ラジアン), "alpha": 透明度(数値)}
					幅と高さの片方のみを指定した場合、もう片方は元の画像のサイズになります。
					透明度は0.0～1.0の間で指定します。
	[戻り値]
		0

drawText(text, x, y, option)
	[説明]
		テキストを描画します。
	[引数]
		text - 描画するテキスト(文字列)
		x - 開始の水平座標(数値)
		y - 開始の垂直座標(数値)
		option - オプションを連想配列で指定します。
					{"width": 線幅(数値), "color": 16進数のカラーコード(文字列), "fill": 塗りつぶし(数値), "fontstyle": フォントスタイル(文字列), "fontsize": フォントサイズ(数値), "fontface": フォント(文字列)}
					fillはデフォルトは1で、0を指定すると中抜き文字の描画になります。
					フォントスタイルはnormal、bold、italic、obliqueのいずれかを指定します。
	[戻り値]
		0

measureText(text, option)
	[説明]
		テキストの描画サイズを取得します。
	[引数]
		text - テキスト(文字列)
		option - オプションを連想配列で指定します。
					{"fontstyle": フォントスタイル(文字列), "fontsize": フォントサイズ(数値), "fontface": フォント(文字列)}
					フォントスタイルはnormal、bold、italic、obliqueのいずれかを指定します。
	[戻り値]
		描画サイズ
		{"width": 幅, "height": 高さ}

rgbToPoint(x, y)
	[説明]
		指定座標の色を取得します。
	[引数]
		x - 水平座標(数値)
		y - 垂直座標(数値)
	[戻り値]
		RGBの配列
		{"r": 赤を示す255までの数値, "g": 緑を示す255までの数値, "b": 青を示す255までの数値}

rgbToHex(rgb)
	[説明]
		RGBの配列を16進数のカラーコードに変換します。
	[引数]
		rgb - RGBの配列
				{"r": 赤を示す255までの数値, "g": 緑を示す255までの数値, "b": 青を示す255までの数値}
				キーの大文字小文字は区別しません。
	[戻り値]
		16進数のカラーコード(文字列)

hexToRgb(hex)
	[説明]
		16進数のカラーコードをRGBの配列に変換します。
	[引数]
		hex - 16進数のカラーコード(文字列)
	[戻り値]
		RGBの配列
		{"r": 赤を示す255までの数値, "g": 緑を示す255までの数値, "b": 青を示す255までの数値}

inTouch()
	[説明]
		タッチ(マウス)位置を返します。
	[引数]
		なし
	[戻り値]
		タッチ状態
		{"x": 水平座標, "y": 垂直座標, "touch": タッチ状態, "button": ボタン, "pos": {{水平座標, 垂直座標}, ...}}
		タッチ状態が0の場合は現在はタッチされておらず、最終のタッチ座標になります。
		buttonは0が左クリック、1が真ん中(ホイール)クリック、2が右クリックになります。
		posはマルチタッチの座標が入ります。

inKey(key)
	[説明]
		キーボード入力を返します。
	[引数]
		key - 押されているか確認するキー文字列を指定します。
				配列で指定した場合は配列内のすべてのキー文字列が押されているか確認します。
				キー文字列はJavaScriptのKeyboardEvent.keyと同値になります。
	[戻り値]
		引数が指定されていない場合は、押されているキー文字列の配列を返します。
		引数が文字列で指定されている場合は、キーが押されている場合は1を返し、押されていない場合は0を返します。
		引数が配列で指定された場合はすべてのキーが押されている場合は1を返し、押されていないキーがある場合は0を返します。

playSound(note, start, end, volume = 1)
	[説明]
		指定された周波数を指定した時間再生します。
	[引数]
		note - 周波数(数値)
				文字列を指定した場合は対応する周波数に変換されます。後ろに数字を入れるとオクターブになります。
				'C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'
				オクターブを省略した場合は4になります。フラット(b)には対応していません。
					例) playSound("C4", 0, 500)
		start - 鳴り始めるまでの時間のミリ秒(数値)
		end - startからの再生の長さのミリ秒(数値)
		volume - ボリューム、省略時は1(数値)
	[戻り値]
		0

playMusic(notes, option)
	[説明]
		複数の周波数を連続で再生します。
	[引数]
		notes - noteの配列
				{note, length, volume}
				noteを文字列で指定した場合は対応する周波数に変換されます。後ろに数字を入れるとオクターブになります。
				'C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'
				オクターブを省略した場合は4になります。フラット(b)には対応していません。
					例) playMusic({{"C4", 500}, {"D4", 500}, {"E4", 500}})
				volumeは省略可能です。

				配列に以下のキーと値を設定すると特別な意味になります。
				start: 開始位置、複数の音を同時に鳴らす場合には開始位置を0にして別の音を設定します。
					例) playMusic({{"C4", 800}, {"start": 0}, {"E4", 800}, {"start": 0}, {"G4", 800}})
				volume: これより後のボリューム
		option - オプションを連想配列で指定します。
					{"repeat": 繰り返しフラグ(数値)}
	[戻り値]
		0

bgm(notes, option)
	[説明]
		BGMを再生します。
		再生中のBGMがあれば停止してから、指定したnotesを繰り返し再生します。
		playSound()やplayMusic()で鳴らしている効果音は停止しません。
		notesを省略した場合はBGMを停止します。
			例) bgm({{"C4", 500}, {"E4", 500}, {"G4", 500}})
			例) bgm() // BGMを停止
	[引数]
		notes - playMusic()と同じ形式のnoteの配列、省略可
		option - オプションを連想配列で指定します。
					{"repeat": 繰り返しフラグ(数値)}
					省略時は1(繰り返す)。0を指定すると1回だけ再生します。
	[戻り値]
		0

stopSound()
	[説明]
		再生されているサウンドをすべて停止します。
		bgm()で再生中のBGMも停止します。
	[引数]
		なし
	[戻り値]
		0

■数値処理API (math.pg0)

以下のインポート文により利用することができます。
#import("lib/math.pg0")

abs(num)
	[説明]
		絶対値を返します。
	[引数]
		num - 変換する数値
	[戻り値]
		絶対値

■文字列API (string.pg0)

以下のインポート文により利用することができます。
#import("lib/string.pg0")

trim(str)
	[説明]
		文字列の前後をトリミングする。
		トリミング対象は空白(" ")、タブ("\t")、改行、全角空白などの空白文字(JavaScriptのtrimと同じ)となる。
	[引数]
		str - トリミングする文字列
	[戻り値]
		トリミングされた文字列

to_lower(str)
	[説明]
		英文字列を小文字に変換する。
	[引数]
		str - 小文字に変換する文字列
	[戻り値]
		小文字に変換された文字列

to_upper(str)
	[説明]
		英文字列を大文字に変換する。
	[引数]
		str - 大文字に変換する文字列
	[戻り値]
		大文字に変換された文字列

str_match(ptn, str)
	[説明]
		ワイルドカードを使って、文字列を比較する。
		「*」で任意の複数文字列に一致し、「?」で任意の一文字に一致する。
		大文字と小文字は区別しない。
	[引数]
		ptn - 比較元のパターン（こちらにワイルドカードを指定する）
		str - 比較する文字列
	[戻り値]
		一致した場合は1を返し、一致しない場合は0を返す。

substring(str, begin, length = -1)
	[説明]
		文字列から部分文字列を抽出する。
	[引数]
		str - 抽出対象の文字列
		begin - 開始インデックス
			（負数は文字列の末尾からのインデックスとなる）
		length - 抽出する長さ（負数は末尾までの長さとなる）
	[戻り値]
		抽出された部分文字列

in_string(str, search, from = 0)
	[説明]
		文字列内の指定文字列の位置を検索する。
	[引数]
		str - 検索対象の文字列
		search - 検索する文字列
		from - 検索を開始するインデックス（負数は0として扱う）
	[戻り値]
		見つかった文字列のインデックスを返す。
		見つからない場合は -1 を返す。

split(str, separator)
	[説明]
		区切り文字列で文字列を分割する。
	[引数]
		str - 分割対象の文字列
		separator - 区切り文字列（空文字列を指定すると1文字ずつに分割する）
	[戻り値]
		分割した文字列が入った配列

#import("lib/io.pg0")
